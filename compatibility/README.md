# Compatibility data

This directory contains versioned, machine-readable RTD acquisition
compatibility requirements and evidence vocabulary.

The data is separate from `conformance/`:

- `conformance/` describes deterministic observable behavior shared by
  independent implementations;
- `compatibility/` describes RTD-family acquisition requirements and the
  evidence needed to make hardware/configuration compatibility claims.

Neither dataset substitutes for physical validation. Real-hardware evidence is
recorded separately and referenced by compatibility records when it exists.

See [`v1/README.md`](v1/README.md) for the current format.
