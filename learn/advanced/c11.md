# Portable C11

The project plans an independent portable C implementation for embedded and
cross-language use.

The C side is intentionally not a Python extension module. Python and C are
separate implementations that can converge on the same language-neutral
behavioral contracts.

## Current alpha foundation

The first portable C contract is a small SPI HAL in `c/include/rtd_acquire/spi.h`.
It carries:

- caller-owned opaque context;
- effective SPI settings; and
- a full-duplex transfer callback.

The contract requires no dynamic allocation and no Arduino-specific headers, so
it can be compiled with an ordinary C11 host compiler before platform adapters
are added.

## Why start with the HAL?

Freezing the platform boundary first lets future HERO/Arduino, STM32, ESP32,
RP2040, Linux, and other adapters implement the same capability without baking
one board family into the acquisition core.
